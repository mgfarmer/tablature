# Icon Files

This extension requires icon files in PNG format with the following dimensions:
- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Creating Icons

You can create icons using:

1. **Online Tools:**
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/
   - https://www.iconfinder.com/

2. **Design Software:**
   - Figma (free, web-based)
   - Adobe Illustrator
   - Inkscape (free, open-source)
   - GIMP (free, open-source)

3. **Quick Placeholder:**
   Use a simple colored square with the letter "T" for Tablature

## Recommended Design

For a tab manager extension, consider using:
- Tab icon metaphors (folder tabs, browser tabs)
- Grid/organize icons
- The brand colors from the extension: #667eea and #764ba2

## Installation Note

Until you add actual icon files, the extension will show a default Chrome extension icon. The extension will still function normally.
